# js_playground

## Installation
- For the javascript project: `sudo apt install nodejs npm -y`
- For the python backend: `pip install flask`

## Run
### Javascript
- In the root of this repository, run `npx vite`.
- Open the address http://localhost:5173/ in your browser.

### Python backend
- In another terminal, run `export FLASK_APP=server.py; export FLASK_ENV=development; flask run`
